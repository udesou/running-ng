Modifiers available for data collection:

- `perf_grp1` — task-clock, page-faults, cycles, instructions
- `perf_grp2` — cycles, stalled-cycles-frontend/backend

- `perf_grpN` is a `PerfAndOllyAttach` type — runs both perf stat and olly simultaneously

## Decisions made

1. Use `notebooks/macrobench_loader.py` as the data loader — avoid duplication.
2. Feature matrix = olly features only (initially); perf columns added automatically when available.
3. Normalise by z-score first; consider rate-normalisation (per-second) in a later iteration.
4. Reference runtime for clustering: `ocaml-trunk` (use a single runtime to isolate benchmark character from GC implementation differences).
5. Pipeline lives in `experiments/clustering/pipeline/` as importable Python modules driven by `run_pipeline.py`.
